# AirRC M0 骨架与参考分支评价

固定验证 38 例、测试 38 例，共 76 例、228 组病例/结构。复用已导出的 M0 预测与统一编码 GT，没有训练或推理。全部结构成功计算，无缺失、无失败、无未定义指标，六项比率各 split/class 的 n_valid 均为 38。

指定最小长度为 3.0 mm，主指标为 BDR80；BDR90 仅为敏感性分析。12 项合成测试在原评估环境通过，包含完美/漏检/Y 型漏枝、断点、伪枝、各向异性、闭环、孤立点、短枝、多连通分量及26邻接拐角检查。全量前已检查两例验证病例三类参考图及覆盖图。

骨架使用 evaluate_airrc.skeletonize、scikit-image 0.21.0 的 Lee 算法。228 组重算 clDice 与原值完全一致，最大绝对差为 **0.0**。旧指标及结果文件保留。骨架 Recall/Precision 为体素计数，分支覆盖率使用边长半权重；两者口径不同。

枝段是无根拓扑参考路径，不代表解剖命名或分支级别。26邻接的相邻分叉体素收缩为簇，真正簇内部长度不计入；仅有两个外部出口的拐弯簇作为 degree=2 转弯恢复单条最短内部连接，不产生伪分叉。GT图完全不依赖预测。覆盖型 BDR 不保证连续，短断点后仍可能达到80%，不能称为“完整连接率”。3 mm 是本项目预设阈值，不是 HiPaS 官方参数。

全量复核时只修正了浮点累加产生的极小覆盖率越界，采用稳定求和和[0,1]数值边界；GT图源代码未改变，228份GT图缓存保持完全相同并复用。3 mm、80%、90%阈值及零空间容差均未调整。
